# Révision JOIV avec comparaison de quarante trajets

Version v2.0.0 publiée le 15 octobre 2026. DOI : https://doi.org/10.5281/zenodo.23389655. Le dépôt actualisé contient le dossier de révision du 12 octobre 2026, le manuscrit anglais, la réponse aux neuf remarques et les calculs reproductibles.

Le modèle de nouveaux centres conserve les 26 pôles existants et compare 24 optimisations. Le complément des 40 trajets ajoute quatre variantes de graphe et 160 comparaisons, pas 160 optimisations. Le graphe principal donne 29 distances comparables et 11 cas sans chemin. Les contrôles cartographiques et deux références commerciales sont limités : aucune validation indépendante de terrain ou de couverture régionale n’est revendiquée.

Les scripts initiaux sont conservés comme version historique. Le README identifie les fichiers actuels et les instructions Windows. Les licences et empreintes des sources sont documentées. Les couches brutes lourdes et les sources restreintes ne sont pas toutes redistribuées.

L’archivage Zenodo est confirmé. La présente mise à jour de citation est postérieure à l’archive; le tag et les calculs v2.0.0 restent inchangés. Le DOI 23389655 est celui à citer pour cette version.
