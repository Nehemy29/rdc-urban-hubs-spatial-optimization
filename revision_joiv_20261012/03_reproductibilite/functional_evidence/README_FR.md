# Complément énergie et économie
Exécution : py compute_energy.py puis py build_supplement.py
Dépendances : pandas, numpy, geopandas, pyproj, shapely, python-docx.
Le fichier routier n’est pas nécessaire : conserver new_hubs/results/all_new_hub_selections.csv dans le dossier parent.
Les distances ajoutent du contexte historique, sans reclasser les sites ni prétendre à un raccordement disponible. La couche Banque mondiale est sous CC BY 4.0. Les données nationales WBES sont transcrites du profil officiel et ne sont pas extrapolées aux sites. Les sources actuelles insuffisantes ne sont pas remplacées par des valeurs inventées.
